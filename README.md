ESCAPE: THE LAST ROUTE — UNITY 6 PROJECT

Unity 6 project foundation for the planned 50-room 3D escape game.

Includes:
- 50-room / 5-phase progression architecture
- character selection state
- third-person movement
- mobile/tilt input hooks
- interaction framework
- room definitions
- puzzle framework
- NPC dialogue framework
- choices and persistent consequences
- save/load state
- timer/tension audio controller
- UI hooks
- Android-ready project structure

This is the actual project foundation. Professional 3D characters, bespoke environments,
voice acting, music and final cinematic assets still need to be imported/created in the
production pipeline; they are not falsely represented as finished here.

Setup:
1. Install Unity 6 with Android Build Support.
2. Open this folder in Unity Hub.
3. Add/use the ETLR editor builder described in the scripts.
